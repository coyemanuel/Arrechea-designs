# Arrechea Designs

Portafolio personal de desarrollo web frontend: proyectos, aprendizajes y contacto.

## Características

- Diseño oscuro con glassmorphism y acentos violeta, cian y esmeralda
- Efectos hover fluidos en botones, tarjetas, chips y enlaces
- Animaciones de entrada al hacer scroll
- Menú responsive con resaltado de la sección activa
- Accesibilidad: enlace para saltar al contenido, etiquetas ARIA y soporte de `prefers-reduced-motion`

## Estructura

```
.
├── index.html       # Estructura de la página
├── css/style.css    # Estilos
├── js/main.js       # Menú, animaciones y navegación
├── favicon.svg      # Ícono de la pestaña
└── README.md
```

## Ver el sitio

Abre `index.html` en el navegador. No necesita instalación.

## Publicarlo

- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`
- **Netlify:** arrastra la carpeta completa a [Netlify Drop](https://app.netlify.com/drop)

## Personalizar

- Colores: variables `--violet`, `--cyan` y `--emerald` al inicio de `css/style.css`
- Proyectos y entradas del blog: edita las tarjetas en `index.html`
